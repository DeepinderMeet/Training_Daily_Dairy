## What is CNN?

A **Convolutional Neural Network (CNN)** is a deep learning model specially designed for processing image data. It automatically extracts useful features from images, making it highly effective for computer vision applications.

---

## Key Concepts Covered

- Images are represented using pixels, with RGB channels for color images.
- The **Convolution Layer** uses filters to extract important features like edges and textures.
- The output of convolution is called a **feature map**.
- **ReLU** is applied to introduce non-linearity into the network.
- **Pooling** reduces the size of feature maps while retaining important information.
- **Fully Connected Layers** use the extracted features to perform the final prediction or classification.
