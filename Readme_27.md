## Image Transformations

The following operations were performed:

### Image Resizing

- Changed image dimensions using OpenCV.
- Used resizing for preparing images for different applications.

### Image Cropping

- Extracted a specific region from an image.
- Learned how cropping focuses on the required area.

### Image Flipping

- Flipped images horizontally and vertically.
- Understood different flip modes provided by OpenCV.

### Image Rotation

- Rotated images using a transformation matrix.
- Learned how rotation angle and scaling affect the final output.
