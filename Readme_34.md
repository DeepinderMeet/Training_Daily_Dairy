# Day 34 – Facial Emotion Recognition GUI

Today, I developed the graphical user interface (GUI) for the **Facial Emotion Recognition** project using **CustomTkinter**. The application provides a user-friendly interface for real-time emotion detection using a webcam.

## Project Title

**Facial Emotion Recognition GUI**

---

## Topics Learned

- CustomTkinter GUI
- Live Webcam Feed
- Real-Time Emotion Detection
- Confidence Score Display
- FPS Counter
- Snapshot Saving
- Background Threading

---

## Project Features

The GUI includes:

- Live webcam preview.
- Real-time emotion prediction.
- Emotion confidence bars.
- FPS display for performance monitoring.
- Option to save snapshots.
- Responsive interface using background threading.
