# Day 33 – Real-Time Facial Emotion Recognition

Today, I completed the real-time implementation of the **Facial Emotion Recognition** project by integrating the trained CNN model with **OpenCV**. The application detects faces through a webcam, predicts emotions, and displays the results in real time.

## Project Title

**Facial Emotion Recognition**

---

## Topics Learned

- Loading Trained CNN Model
- Haar Cascade Face Detection
- Webcam Integration
- Face Preprocessing
- Emotion Prediction
- Real-Time Detection

---

## Project Implementation

The application performs the following tasks:

- Captures live video from the webcam.
- Detects faces using the Haar Cascade Classifier.
- Preprocesses detected faces for the CNN model.
- Predicts the facial emotion.
- Displays the predicted emotion on the live video feed.
