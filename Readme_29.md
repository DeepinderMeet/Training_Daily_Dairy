# Day 29 – Contour Detection and Shape Recognition

Today, I learned how to detect object boundaries and recognize basic geometric shapes using **OpenCV**. I explored the complete process from image preprocessing to contour detection and shape labeling.

## Topics Learned

- Grayscale Conversion
- Image Thresholding
- Contour Detection
- Contour Approximation
- Shape Recognition
- Shape Labeling

---

## Practical Work

The following steps were performed:

- Converted images into grayscale.
- Applied binary thresholding.
- Detected contours using OpenCV.
- Approximated contour boundaries.
- Identified shapes based on their corner points.
- Displayed the detected shape names on the image.
